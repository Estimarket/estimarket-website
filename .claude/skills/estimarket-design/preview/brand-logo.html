Rules

  • Clear space = half the block height, all four sides.
  • Minimum width — lockup 120px, badge 160px, mark 16px.
  • Two-tone has a ~96px floor; the orange bar muddies below it. Use -navy.
  • Never rebuild the lockup from the mark plus typed text — the spacing is artwork.
  • Orange #E85D26 is also the CTA colour. Logo near a button → -navy.
